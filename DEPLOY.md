# Deploy to Hostinger public_html

## Preferred: Git deploy from this repo

1. hPanel → Advanced → Git
2. Disconnect old **Al-Falah-Marketing** monorepo if connected
3. Connect **New-Al-Falah-Website**, branch **main**, deploy directory **public_html**
4. Deploy once
5. Confirm `public_html/index.html` exists

## Alternative: zip from Google Drive

Download the recovery zip from Drive, extract **into** public_html (not a subfolder).

## Source

All site files in this repo were built from the local Al-Falah project recovery (not pulled from the old monorepo).
